# Проектирование ИТ-систем: Системный анализ и декомпозиция бизнес-процессов

Практический проект в рамках ИТ-обучения, направленный на моделирование логической архитектуры систем, работу с требованиями и структурирование бизнес-логики ИТ-продуктов на начальных этапах жизненного цикла (SDLC).

## Цели и задачи проекта
* **Системный анализ предметной области:** Выявление источников информации, сбор и консолидация разрозненных бизнес-требований.
* **Управление понятийным аппаратом:** Разработка и ведение единого глоссария проекта для синхронизации понимания между бизнесом и технической командой.
* **Проектирование и декомпозиция:** Определение ролевых моделей, функциональных блоков и объектных связей для автоматизации сервисов.

---

## Что было сделано (Содержимое каталога `src/`)

Все аналитические артефакты и решения структурированы и распределены по соответствующим бизнес-кейсам в директории `src/`:

### 1. Анализ ИТ-инфраструктуры и сбор требований
* Проведен детальный анализ стейкхолдеров, нормативно-правовых актов и регламентов.
* Спроектирован **каталог (реестр) источников информации** с приоритизацией изучения документов.
* Разработан **единый глоссарий проекта** (устранение двусмысленности в терминологии ИТ/Бизнес).

### 2. Бизнес-кейс: Автоматизация сети барбершопов (Онлайн-запись)
* Проанализированы цели автоматизации (увеличение клиентской базы, снижение ручного труда).
* Проведена **функциональная декомпозиция** процесса онлайн-записи (регистрация, выбор мастера/услуги, валидация свободных слотов).
* Спроектирована **объектная (компонентная) декомпозиция** услуг системы (разделение на парикмахерские, косметические услуги и вложенные подуровни).
* Смоделирована логика интеграции с внешними каналами связи (Telegram, WhatsApp, SMS-шлюзы) для автоматических уведомлений.

### 3. Бизнес-кейс: Проектирование Логистического Стартапа (Служба доставки)
* Формализованы требования к ролевой модели системы: Клиент, Оператор, Диспетчер, Курьер, Администратор.
* Выполнена **декомпозиция действий (Use Cases)** для мобильного приложения курьера (просмотр, бронирование, изменение статусов заказа).
* Описана логика межсистемного взаимодействия (интеграция с учетной/бухгалтерской системой для расчета выплат и тарификации поставщиков).

### 4. Методология и правила декомпозиции
* Продемонстрировано владение различными видами декомпозиции: *функциональная, объектная/компонентная, темпоральная (событийная)*.
* Артефакты проверены на соответствие ключевым правилам системного анализа: **подчиненность**, **единственность критерия**, **целостность** (полнота и взаимное непересечение элементов).
